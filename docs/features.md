# FinSight 기능 명세서 (Features Specification)

이 문서는 각 페이지에서 제공되는 **사용자 기능과 시스템 동작**을 정의한다.
API 주소가 아닌 **사용자 행동 → 시스템 동작 흐름** 기준으로 작성한다.

---

# 1. 대시보드 (Dashboard)

## 목적

로그인한 사용자의 학습/투자/랭킹 현황을 한 화면에서 확인할 수 있는 메인 페이지.

## 주요 기능

### 사용자 프로필 표시

* 로그인한 사용자의 닉네임 표시
* 현재 티어 표시
* ISR 점수 표시
* 보유 포인트 표시

### 투자 현황 요약

* 총 투자 원금 표시
* 총 수익 표시
* 수익률 표시

### 최근 업적 표시

* 최근 달성한 업적 최대 3개 표시
* 업적이 없을 경우 기본 업적 표시

### 참여 종목 요약

* 최근 참여한 종목 목록 표시
* 종목명
* 현재가
* 변동률

### 랭킹 미리보기

* 상위 랭커 일부 표시
* 사용자 자신의 순위 표시

## 동작 흐름

1. 페이지 진입
2. 로그인 여부 확인
3. 사용자 프로필 정보 로드
4. 투자 현황 데이터 로드
5. 최근 업적 데이터 로드
6. 참여 종목 데이터 로드
7. 랭킹 요약 데이터 로드

## 예외 처리

* 로그인 정보가 없으면 로그인 페이지로 이동
* 투자 데이터가 없으면 기본 안내 문구 표시
* 업적 데이터가 없으면 기본 업적 표시

# 2. 교육실 (Education)

## 목적

사용자가 주식 기초 지식을 학습하고 진행도를 관리할 수 있는 페이지.

## 주요 기능

### 교육 콘텐츠 목록

* 전체 교육 목록 조회
* 카테고리 필터
* 검색 기능

### 교육 상세 보기

* 강의 제목
* 설명
* 핵심 학습 포인트

### 학습 진행도 표시

* 전체 학습 진행률
* 오늘의 학습 목표
* 연속 학습일

### 교육 완료 처리

* 사용자가 학습 완료 버튼 클릭
* 완료 시 포인트 지급
* 진행도 업데이트

## 동작 흐름

1. 페이지 진입
2. 교육 콘텐츠 목록 조회
3. 카테고리 또는 검색 필터 적용
4. 강의 선택 시 상세 내용 표시
5. 학습 완료 시 진행도 업데이트

## 예외 처리

* 교육 데이터가 없으면 안내 메시지 표시
* 진행도 데이터가 없으면 0%로 표시

# 3. 전략실 - 주식 (Strategy / Stocks)

## 목적

사용자가 종목을 탐색하고 차트를 분석할 수 있는 페이지.

## 주요 기능

### 종목 검색

* 종목명 또는 종목코드 검색

### 대표 종목 표시

* 인기 종목
* 급상승 종목
* 급하락 종목

각 탭마다 대표 종목 차트 표시

### 종목 상세 정보

* 종목명
* 현재가
* 변동률
* 거래량

### 차트 표시

* 기간별 차트 조회
* 가격 흐름 확인

### 관심 종목 관리

* 관심 종목 추가
* 관심 종목 제거

## 동작 흐름

1. 페이지 진입
2. 기본 대표 종목 차트 표시
3. 사용자가 탭 선택
4. 선택한 탭의 대표 종목 데이터 표시
5. 사용자가 종목 검색
6. 선택한 종목 상세 정보 표시

## 예외 처리

* 검색 결과 없음 표시
* 차트 데이터 없음 안내

---

# 4. 전략실 - 퀴즈 (Strategy / Quiz)

## 목적

사용자가 퀴즈를 통해 학습 내용을 점검할 수 있는 페이지.

## 주요 기능

### 랜덤 퀴즈 제공

* 난이도별 퀴즈 제공

### 문제 풀이

* 객관식 선택

### 정답 제출

* 정답 여부 확인

### 해설 제공

* 정답 설명 표시

### 풀이 여부 확인

* 이미 푼 문제인지 확인

## 동작 흐름

1. 페이지 진입
2. 랜덤 퀴즈 조회
3. 사용자가 보기 선택
4. 정답 제출
5. 결과 및 해설 표시

## 예외 처리

* 문제 로드 실패 시 재시도 안내
* 답안 선택 없이 제출 시 경고

---

# 5. 랭킹 (Ranking)

## 목적

사용자의 투자 성과 기반 순위를 확인하는 페이지.

## 주요 기능

### 티어별 랭킹

* 브론즈
* 실버
* 골드
* 플래티넘

### 순위 표시

* 순위
* 닉네임
* 점수

### 내 순위 표시

* 로그인 사용자 순위 강조

### 상위 랭커 표시

* 상위 N명 표시

## 동작 흐름

1. 페이지 진입
2. 티어별 랭킹 조회
3. 사용자 순위 조회
4. 랭킹 목록 화면 표시

## 예외 처리

* 랭킹 데이터 없음 안내
